# Monitorizarea Consumului de Resurse

Acest proiect ajută utilizatorii să monitorizeze și să optimizeze consumul zilnic de resurse naturale, cum ar fi apă, energie electrică și gaze.

## Funcționalități

- Adăugarea consumului zilnic de apă, energie și gaze.
- Vizualizarea consumului în timp printr-un grafic interactiv.
- Sfat pentru economisirea resurselor naturale.

## Tehnologii Folosite

- **HTML** pentru structura paginii.
- **CSS** pentru stilizarea paginii.
- **JavaScript** pentru interactivitate și manipularea datelor.
- **Chart.js** pentru generarea graficelor.
